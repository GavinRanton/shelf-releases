# Shelf

A clipboard manager that lives in your Mac's menu bar. It remembers text, images,
files, links, emails and colours, keeps them encrypted on your Mac, and gets any
of them back with a keystroke.

**[Download the latest version](https://github.com/GavinRanton/shelf-releases/releases/latest)**

Requires macOS 14 Sonoma or later. Apple silicon and Intel.

---

## Install

1. Open the dmg and drag **Shelf** into **Applications**.
2. Launch it from Applications. Shelf is signed with an Apple Developer ID and
   notarised by Apple, so it opens with no warning.
3. Press **⌃⇧Space** to open the panel.
4. The first time you paste from Shelf, macOS asks for **Accessibility**
   permission. Allow it in *System Settings → Privacy & Security → Accessibility*.
   Without it Shelf still copies to the clipboard, it just cannot paste for you.

## What it does

| | |
|---|---|
| **History** | Everything you copy, searchable, with previews for images, links and code |
| **Two layouts** | A shelf along the bottom of the screen, or a ledge down the side |
| **Snippets** | Type `;;sig` anywhere and Shelf swaps in the text |
| **Sequential paste** | Paste your last several copies one after another into a form |
| **Screenshots** | Captures land in your history automatically |
| **Image text** | Text inside screenshots is recognised and searchable |
| **Ask it** | "find the link I copied yesterday", answered by Apple's on-device model |

---

## Privacy

Everything stays on your Mac, encrypted, in a file only your account can read.
No account, no server, no sync, no analytics. Password managers, Keychain Access
and secure text fields are never recorded.

Full statement: [PRIVACY.md](PRIVACY.md)

---

## Updates

Shelf checks here once a day and offers to install new versions. Every update is
signed, and a download that fails the signature check is rejected before it is
unpacked. You can turn automatic checks off in *Settings → About*.
